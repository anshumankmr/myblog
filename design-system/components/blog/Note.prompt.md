A short, untitled post (a "note"): one to three sentences in a flat sunken block with a mono timestamp that links to its permalink. Use for quick thoughts that don't deserve a full post.

```jsx
<Note date="2026-09-27" time="11:48" href="/notes/2026-09-27-1148/">
  First half marathon back: 21.3 km, 2:46:48 moving.
</Note>
```

- Stack notes in a column with a 12px gap. Never in a masonry grid, never tilted, never yellow.
- No title and no tags. If it needs a title, it's a post.
- Inline links are fine (`<a>` inside children). Link to a full post with "Post title →".
