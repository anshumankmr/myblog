# Blog UI Kit — anshumankumar.net

Click-through recreation of anshumankumar.net, the personal blog of Anshuman Kumar
(software engineer at Flexera, Bangalore). Copy and posts come from the live site.

**Screens:** Home (hero + section guide + recent posts) · Posts (grouped by year) ·
Article · Notes · Now (training, rides, calories, films) · About · Contact. Dark mode
via the header toggle.

| File | What |
|---|---|
| `index.html` | Shell: routing, theme state |
| `data.js` | Real posts and facts; sample notes/rides/calories/films (marked) |
| `Chrome.jsx` | Header (Devanagari wordmark, nav) + footer |
| `Screens.jsx` | Home, Posts, Article |
| `Screens2.jsx` | About, Contact |
| `Screens3.jsx` | Notes, Now |

`_pensees-*.bak` files are an abandoned earlier direction, kept for reference.
